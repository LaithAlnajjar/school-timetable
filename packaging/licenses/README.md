# Qt license texts

These unmodified license texts come from Qt's official `qtbase` repository at
`v6.10.2`, under `LICENSES/`:
https://github.com/qt/qtbase/tree/v6.10.2/LICENSES

They supplement notices carried by the installed PySide/Shiboken wheels. Build
scripts copy them, the installed dependency notices and Python's runtime license
into the distribution's LICENSES folder. Source links and library replacement
permissions are recorded in THIRD_PARTY_NOTICES.txt.
